# Curso-de-Git-e-GitHub---Gustavo-Matos
Curso sobre como trabalhar com Git e GitHub do Gustavo Matos.

# Comandos Ressaltados Durante o Curso:

0. git config --global user.name "Seu Nome": ara o git te identificar;
1. git config --global user.email seu email: para o git identificar teu email
2. mkdir: criação de pastas;
3. touch: criação de arquicos
4. ls: listar arquivos;
5. cd: transição entre arquivos através de caminhos;
6. rm -r 'nome da pasta ou arquivo': para deletar pastas ou arquivos;
7. git add 'nome do arquivo ou pasta': para colocar no modo stage antes de commitar
8. git add .: colocar todas as alteração no modo stage;
9. git commit: para atualizar o projeto;
10. git status: para visualizar os status do projeto;
11. git log / git log --oneline: visualizar todos os commits detalhados/ visualizar commits resumidos;
12. git checkout: SEGURO, feito para 'voltar no tempo e mudar algo' e transistar entre as branchs;
13. git revert: MENOS SEGURO, feito para retornar a um commit anterior;
14. git reset: NADA SEGURO, feito também para voltar a um ponto anterior, mas sem chance de retorno;
15. git merge 'nome da branch: para mesclar as branchs;
